## 2. 今日已解决问题（P0）

### 2.1 AI 短剧频道无数据（PR #31，已合并）

**发现：**

- `ai_drama_node` 仅 1 次 Kimi `search_json`，无 JSON schema，字段名对不上即全空
- 生产环境 `latest.json` 中 `ai_drama_dashboard` 从未成功填充
- `quality_gate_node` 不检查 AI 看板，空数据也能 `passed: true`

**修复：**

| 改动 | 说明 |
|------|------|
| `src/tools/ai_drama_fetcher.py` | 直爬澎湃新闻 DataEye 月报/百强榜 |
| `config/ai_drama_articles.json` | 月份 → thepaper 文章 ID 映射 |
| `ai_drama_node` 多层兜底 | thepaper → DeepSeek 抽取 → 规则抽取 → 上月 → 通用搜索 → carry-forward |
| `config/ai_drama_llm_cfg.json` | 增加严格 JSON schema |

**验证：** 无 API Key 时可通过 thepaper 规则抽取产出 KPI + 漫剧 TOP5；`data/ai_drama_cache.json` 已有非空缓存。

**待观察：** 合并后需等下一次日报工作流跑完，`latest.json` 才会刷新 AI 看板字段。

---

### 2.2 热门内容频道不更新（PR #31，已合并）

**发现：**

- 前端「🔥 热门内容」读取 `./data/hot_content/latest.json`
- `scripts/generate_hot_content.py` 存在但 **从未加入** `.github/workflows/daily_update.yml`
- 数据停留在 2026-06-22（设计缺口，非爬虫故障）

**修复：**

- CI 每周一（UTC 周一 = 北京时间周一 9:00 定时任务）执行 `generate_hot_content.py`
- 已生成本周数据 `2026-07-06`（红果/晋江/番茄各 10 条）

---

### 2.3 质量门禁静默失败（本 CR / 本分支）

**发现：**

- 门禁失败时图路由 `跳过推送 → END`，`push_node` 不执行
- 飞书 `push_alert` 仅在 `push_node` 内部调用，**门禁失败时无人通知**
- `run_github.py` 不检查 `quality_report.passed`，CI 以 exit 0 结束，显示 `No changes to commit`
- 历史 `all_history.json` 存在 6 月下旬发布空档，与此机制一致

**修复：**

| 改动 | 说明 |
|------|------|
| `src/graphs/nodes/gate_fail_node.py` | 硬性失败时发飞书告警 + 写 `assets/data/quality_gate_last_run.json` |
| `src/graphs/graph.py` | `跳过推送 → gate_fail_node → END` |
| `src/run_github.py` | `evaluate_run_result()` 检查门禁与发布结果，失败 `exit 1` |
| `.github/workflows/daily_update.yml` | 失败时上传门禁诊断 artifact |

## 3. 今日启动的 P1 改动（本分支）

### 3.1 质量门禁分级（降级发布）

**问题：** 演员/行业/快讯等次要模块失败会阻断整站更新，导致 `latest.json` 多天不变。

**策略：**

| 类型 | 检查项 | 行为 |
|------|--------|------|
| **硬性** | 榜单数量、榜单字段、API 鉴权/限流 | 拒绝发布 |
| **软性** | 演员、行业、快讯 URL、观众画像、AI 看板 | 告警 + **降级发布** |

**新增字段：** `quality_report.publish_mode` = `full` | `degraded` | `blocked`

**改动文件：** `src/graphs/nodes/quality_gate_node.py`、`tests/test_quality_gate.py`

---

### 3.2 演员榜平日补充

**问题：** DeepSeek 演员补充仅在周一触发，平日演员不足导致软性告警或空榜。

**修复：** `actor_ranking_node` 在男女频任一不足 10 人时均触发 DeepSeek 补充（周一/平日日志区分）。
