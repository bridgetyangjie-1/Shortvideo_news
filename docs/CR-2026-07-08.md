> Change Record（变更记录）

## 1. 背景

2026-07-08 以**短剧行业数据分析师**视角对全站代码与 `latest.json`（2026-07-07）进行 Review，发现系统「板块齐全、工程完整」，但**数据可信度**不足以支撑投流/选品决策。核心问题：

| 现象 | 影响 |
|------|------|
| 榜单后半段出现「李十三」「王十四」等编号式演员名 | 演员热力榜误导业务方 |
| 厂牌为「蓝海影视工作室」等模板化幻觉 | 供应链分析不可用 |
| 快讯含 `example.com`、虚构剧目《都市奇缘》 | 行业情报不可信 |
| `views_num` 实为周榜热播指数却被当作播放量 | 指标口径混淆 |
| `quality_score: 100` 与 anomalies/alerts 矛盾 | 质量门禁失去公信力 |
| 20/20 部 `series_id` 为空 | 红果详情爬虫链路断裂 |
| 标签「爱情/都市爱情/逆袭」重复且男女频未分列 | 题材风向标粗糙 |
| 行业 KPI 来自静态种子，无大盘消耗 | 缺少投流核心指标 |

---

## 2. P0 已解决问题（数据质量止血）

### 2.1 拦截幻觉演员名 / 厂牌

**根因：** `json_refiner.py` prompt 要求「严禁填未知、从名单猜测」；`fallback.py` 用候选演员池凑数；质量门禁不识别编号式假名。

**修复：**

| 改动 | 说明 |
|------|------|
| `src/utils/data_quality.py`（新增） | `is_hallucinated_actor_name`、`is_suspicious_studio_name`、`sanitize_production_house` |
| `src/tools/actor_name_utils.py` | 扩展识别「李十三」「王十四」等编号式占位名 |
| `json_refiner.py` + `config/enrich_llm_cfg.json` | 无信源留空，禁止编造演员/厂牌 |
| `enrich/fallback.py` | 删除候选池凑数，仅清洗占位名 |
| `quality_gate_node` | 新增 `ranking_hallucination` **硬性门禁**（可疑演员 >2 或可疑厂牌 >3 → blocked） |
| `actor_ranking_node` | 幻觉演员不入热力榜 |

### 2.2 快讯 URL / 内容真实性

| 改动 | 说明 |
|------|------|
| `news_node` | 拦截 `example.com`、Google/Baidu 搜索页；`insight` 为空时从 content「商业洞察」段自动提取 |
| `quality_gate_node` | 新增 `daily_news_url_trust`、`daily_news_insight` 检查；告警按条数扣分 |

### 2.3 热度字段概念澄清

| 改动 | 说明 |
|------|------|
| `DramaRanking.weekly_heat_index` | 新字段，明确表示红果周热播指数 |
| `process_node` / `enrich_node` | 同步写入 `weekly_heat_index` |
| `assets/index.html` | 表格拆分「周热度」与「累计指数」；周榜坐标标注「周热播指数」 |

**版本标记：** v1.14.3

## 3. P1 已解决问题（分析可用性提升）

### 3.1 红果 `series_id` 模糊匹配回填

**问题：** 短剧工程周榜剧名与红果推荐页标题存在标点/空格/季数差异，精确匹配导致 0/20 回填。

**修复：**

| 改动 | 说明 |
|------|------|
| `src/utils/title_matcher.py`（新增） | 剧名归一化 + 四级匹配（精确 → 归一化 → 子串 → 相似度 ≥0.82） |
| `process_node._backfill_hongguo_metadata` | 复用 title_matcher；额外回填演员/简介；日志记录 `series_id` 命中数 |

### 3.2 标签同义词合并 + 男女频分列

| 改动 | 说明 |
|------|------|
| `tag_normalizer.py` | 扩展同义词（爱情→都市爱情、总裁→霸总、逆袭打脸→打脸 等） |
| `genre_distribution_node` | 爽点分类优先于题材；输出 `by_gender.female/male` TOP8 |
| `GenreDistribution.by_gender` | 新模型字段 |
| `assets/index.html` | 热门标签区增加女频/男频双列展示 |

### 3.3 质量分与置信度前端联动

| 改动 | 说明 |
|------|------|
| `utils/data_quality.compute_ranking_confidence` | 按 series_id/演员/厂牌/集数动态计分 |
| `enrich_node` | 写入动态 `confidence_score` |
| `assets/index.html` | 质量面板展示 score/publish_mode/alerts；低置信度显示「待核实」角标 |

### 3.4 行业 KPI：月大盘消耗

| 改动 | 说明 |
|------|------|
| `IndustryData.market_spend` / `market_spend_yoy` | 新字段 |
| `config/industry_seed.json` | DataEye 5 月报：22.62亿 (+8%) |
| `industry_node` | 搜索 prompt 增加大盘消耗字段 |
| 前端 KPI 第 4 卡 | 「破亿爆款剧」→「月大盘消耗」 |

**版本标记：** v1.14.4
